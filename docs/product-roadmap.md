# IFEXA GO — Product Roadmap

## Purpose

This roadmap tracks IFEXA GO's product development priorities, from defining the MVP to testing the platform with real users.

Items are plans until implementation and verification provide evidence of completion.

## Phase 1 — Product Definition

Status: In progress

- [ ] Define the initial target customers.
- [ ] Document the customer ordering journey.
- [ ] Define vendor, agent, rider, and administrator workflows.
- [ ] Prioritise MVP features.
- [ ] Document payment, cancellation, refund, and dispute requirements.

## Phase 2 — Design and Technical Planning

Status: Not started

- [ ] Document the main application screens.
- [ ] Define user roles and permissions.
- [ ] Document the data model.
- [ ] Agree on the technical architecture with the engineering team.
- [ ] Break approved requirements into engineering issues.

## Phase 3 — MVP Implementation

Status: Not started

- [ ] Implement customer registration and authentication.
- [ ] Implement vendor registration and product listings.
- [ ] Implement product discovery and customer requests.
- [ ] Implement order management.
- [ ] Implement agent and rider workflows.
- [ ] Implement essential administrative tools.

## Phase 4 — Testing and Validation

Status: Not started

- [ ] Test the core customer journey.
- [ ] Test vendor order handling.
- [ ] Test agent and rider workflows.
- [ ] Record bugs and their resolutions.
- [ ] Gather feedback from prospective users.
- [ ] Document changes made from user feedback.

## Phase 5 — Pilot Launch

Status: Not started

- [ ] Select initial pilot users and vendors.
- [ ] Run a limited pilot in the initial market.
- [ ] Record completed orders and delivery outcomes.
- [ ] Track user feedback and operational problems.
- [ ] Document lessons and the next product priorities.

## Update Policy

Update this roadmap when priorities change or work is verified. Link relevant GitHub issues, pull requests, tests, and user-feedback evidence.

Do not mark a feature complete merely because work has started.
